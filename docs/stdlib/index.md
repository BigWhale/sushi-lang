# Standard library

The standard library is in eight sections. Each section has a landing page that lists its chapters.

## Sections

- [Core types](core/index.md) - `Result` and `Maybe`
- [Collections](collections/index.md) - arrays, `List`, `HashMap`, strings, sorting and iteration
- [Text](text/index.md) - ASCII byte tools
- [Encoding and compression](encoding/index.md) - Base64, binary, hex, MessagePack and zlib
- [Files and I/O](io/index.md) - console, files, buffered I/O, paths and contracts
- [Networking](net/index.md) - sockets, TCP, UDP, DNS, IP addresses and URLs
- [System](system/index.md) - math, random, time, environment, process and platform
- [Toolchain](toolchain/index.md) - the `.slib` reader

For one page with every module, the import syntax and common patterns, see the [Standard Library reference](../standard-library.md).
