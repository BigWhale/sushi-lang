# One-seam rules

This file holds the one-seam table of the compiler. Each row names one rule, the ONE
place in the code that holds it, and the CI gate that keeps it there. Read this file
before you change compiler code (`sushi_lang/**`, `tests/unit/` gates): if your change
touches a seam, go through the seam. Do not add a second path.

- A row with "no gate" has no CI gate.
- A new gate is a fixture or a Python-source scan, never a pytest test that runs the
  compiler (see the pytest rule in `CLAUDE.md`, Testing).
- A path that starts with `tests/` is under the repository root. Every other path is under
  `sushi_lang/`; a short path (`passes/...`, `generics/...`, `types/...`) is under
  `sushi_lang/semantics/` or `sushi_lang/backend/`, and the row tells which layer.
  `src_sushi/` is `sushi_lang/sushi_stdlib/src_sushi/`.
- A later change can move a file or a gate that a row names (the SHIR/SLIR change, #1270,
  moved many). Do `ls` on a path before you trust it, and correct the row when you find
  the new home.
